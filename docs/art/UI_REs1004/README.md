## 四之二、接进游戏时踩到 / 修掉的三件事

1. **卡底自带一圈很宽的半透明软边 → 游戏里就是"半透明边框"**
   实测 `card_common_bg` 的 alpha：顶部 0~4 行全透明、第 8 行才 112、第 12 行 215，
   底部 172~179 行 195→146→0，左右各 3~4 列同理，**内部也只有 236~245**。
   直接拼上去，卡牌四周会透出桌面/背景，看着像套了个半透明边框。
   → `CardArt` 现在把**卡底与铭牌**的 alpha 压成 1~2 像素的窄过渡（`AlphaCutLo/Hi`），
   并按"不透明外轮廓"重新定位。

2. **卡面要和卡身对齐**
   卡身比卡面小一圈（`CardFactory.BodyInset = 0.955`，圆角处透出桌面）。
   卡面只要留出比那一圈更宽的透明边，透出去的就是**卡身**（深色）—— 又是一条脏边。
   → `CardArt` 把卡牌外轮廓**拉伸铺满卡身矩形**。代价：美术的卡是 0.75 的宽高比、
   游戏里的卡是 0.716，横向压掉约 5%（宁可比例差一点，也不要缝）。

3. **立绘做成"稍微 3D"**
   平铺的 Quad 斜着看就是一张纸。→ `BlenderArt` 现在按贴图的 alpha 剪影**挤出一层厚度**
   （`ThicknessWorld = 0.06`）：正面贴原图、背面同图染深、侧面纯深色。
   四帧取**并集**剪影建一次网格，动画只换贴图 —— 冲压到 move_02 时机器顶部是空的，
   并集网格靠背面同样透明的贴图收住，不会露出"半截机器"。
   为此 `Art/Juicer/**` 的贴图必须开 Read/Write（读 alpha 用）。

## 六、顺带修掉的：手牌特写装不下所有牌

「手牌特写」原来是个写死的机位（`0, 0.52, -1.00` 看 `0, 0, -0.56`），按 4 张牌调的。
把每张牌的四个角投到屏幕上算过：**4 张就已经到 1.16（画面外），5 张 1.47、6 张 1.78** ——
所以最外侧那两张会被切掉。

现在 `TableSetup.ReframeHandView()` 在每次手牌重新布局时按**实际包围盒**重算机位
（`CameraRig.FrameTableBounds`：俯角 52°、横向按水平 FOV、纵深按 `sin(俯角)` 压缩算距离）。
同样的算法复算：4/5/6 张牌 × 1.33 / 1.78 / 2.24 三种画幅，`|ndc|` 都在 **0.86~0.92**，
全部装进画面；牌多的时候是整体拉远，而不是把牌切掉。

机位参数（`HandViewTiltDeg`、`1.06` 的留边）都在代码里，觉得太远/太近改这两个数。
