# 桌面与卡牌美术方案 v1

## 美术方向

主题定为“深胡桃木炼金工坊”。桌面承担场景气氛，卡牌、破壁机和计分量杯承担信息重点。材质用手绘木纹和旧黄铜细线表达炼金工坊感，中心操作区保持安静，避免装饰和道具抢占玩法空间。

主色以深胡桃木、暖棕、旧黄铜和少量暗青绿为主。建议色值：胡桃木 `#382116`、木纹中间色 `#6B4329`、黄铜 `#B58A45`、暗青绿 `#243A36`。卡牌沿用各素材系列自己的颜色，文字与数值保持高对比。

## 桌面构图

- 桌面主体为横向木板，木纹沿桌面长边延伸；上表面使用独立材质，桌边使用纯深木色，避免贴图包裹桌侧后被拉长。
- 中央约七成区域留作净空，供卡牌、破壁机和互动动画使用。
- 黄铜线只收在桌面周边，角落保留很小的炼金几何刻痕；不在中央放大图案，不加入烛台、瓶罐等固定装饰。
- 普通游戏使用胡桃木主题。汞之间改成银白桌面，献祭房改成黑灰桌面；离开隐藏房时恢复原材质。

## 卡牌轮廓与数值

- 卡牌剪影以美术卡图自身的不规则外轮廓为准，实体侧壁透明，不再露出米白或白色壳边。
- 普通卡不叠加白色稀有度框；稀有与传说保留银色、金色识别框。
- 不添加独立长方形底板或外扩角料。边缘装饰不得超出卡图轮廓。
- H/D/V 数值继续落在素材卡自带的菱形、圆形和方形数值牌中，颜色取对应系列色并保证可读性。
- 法术栏使用卷轴模型，不制作卡面，不显示卡牌式属性角标。

## UI 配色建议

UI 面板以暗青绿和深木色作底，细黄铜线作分隔与焦点提示。按钮默认使用暖棕，选中和可购买状态使用黄铜色，禁用状态降低明度与饱和度。避免整圈白描边、亮白投影和额外角标；交互反馈优先使用颜色变化、轻微缩放和柔和高光。

## 已接入内容

- 新增桌面材质：`UnityProject/Assets/Resources/Art/Table/alchemy_workbench_surface.png`。
- `TableSetup` 在桌面上表面铺设独立材质平面，并在侧面保留纯色木材；隐藏房间通过同一材质层切换银白或黑灰主题。
- `CardArt` 移除普通卡的白色稀有度框。
- `CardFactory` 将剪影卡的挤出侧壁设为透明，减少卡图轮廓外的浅色边缘。

## 美术验收

1. 俯视与低角度检查桌面，确认木纹没有绕边拉伸，黄铜线没有进入中央操作区。
2. 检查普通、稀有、传说卡的外沿：普通卡没有白框，卡图外没有米白侧边；银框和金框仍可辨认。
3. 检查桌面卡片遮挡关系，确认纹理对比度不会干扰卡牌图案与数值。
4. 进入汞之间、献祭房并离开，分别确认主题换色和木纹恢复。
