### 4.2 形态转换：**删掉重复行**是这一版最大的结构变化

v2.1 的卡表为了让 `EnchantRules` 的每条规则都能找到产物，给同一张卡写了**多条指向同一产物的行**
（例：「可熔 + 热 → 熔融铜」和「遇热 + 热 → 熔融铜」）。v3.0 定稿**每张卡只保留定稿写的那几条**，
于是这些重复行被删掉了：

| 卡名 | 删掉的形态转换行 |
|---|---|
| 冰 | 遇热 + 热 → 水 |
| 铜 / 铁 | 遇热 + 热 → 熔融铜 / 熔融铁 |
| 熔融铜 / 熔融铁 / 熔融金 | 液体 + 热 → 铜蒸气 / 铁蒸气 / （无变化） |
| 铜蒸气 / 铁蒸气 / 汞蒸气 | 可熔 + 热 → 熔融铜 / 熔融铁 / 汞 |
| 铜蒸气 / 铁蒸气 | 遇酸 + 酸 → 铜溶液 / 铁溶液 |
| 铜溶液 / 铁溶液 / 黄金 / 熔融金 / 汞 / 汞蒸气 / 固态汞 / 硫磺液 / 熔融玻璃 | 遇酸 + 酸 → **无变化（原因）** 这类声明行 |
| 沙 | 遇热 + 热 → 熔融玻璃 |

**后果（重要）**：标签（遇热 / 金属 / 可熔 / 液体 / 可溶）还在卡上，规则表照样会命中，
但卡表里没有对应产物了 → 离线报告的「规则表接不上」从 v2.1 的 0 条变成 **22 条**
（"启动时规则命中却不变形"）。这不是回归，是**数据先落地、实现下一阶段做**，
但要请策划确认：这 22 处到底是"这些卡就是不该有那个形态"，还是"定稿漏写了产物"。
逐条清单见 `docs/卡牌数值_v3.0_缺口报告.md` §3.5。

### 4.4 改「启动」（逐卡）

v2.1 的启动文本普遍比定稿短（很多卡是"无"），v3.0 定稿把每张卡的启动都扩写了。
只列**有实质差异**的（"句末句号有无""标点全半角"这类不算）：

| 卡名 | v2.1 启动 | v3.0 启动（要点） |
|---|---|---|
| 外星合金 | 额外消耗其他素材H。 | 额外消耗其他素材 H **1 点**（给了实数） |
| 水 | 消耗刀片所有热层数，额外产生一张水蒸气；… | **前面多了「不消耗刀片H」**；后面三条消耗/产出不变（"刀片"二字精简） |
| 水蒸气 | （同 v3.0） | 不变 |
| 铜溶液 | 若刀片有酸，则本次启动得分翻倍。 | **多了「不消耗刀片H」** |
| 铁溶液 | 空 | **「不消耗刀片H」**（v2.1 是空的） |
| 熔融铁 | …每消耗一层，获得5分；且刀片H+1。 | 多了「**不消耗刀片H**，且刀片H+1」 |

> ★ 汇总：**v3.0 把「不消耗刀片H / 不消耗H」写回了 8 张卡**（水、铜溶液、铁溶液、熔融铁、熔融金、盐溶液、汞、熔融玻璃）——

> 请策划确认：这 8 张卡的"不消耗 H"到底做不做（做的话 §四.1 那句要改）。
