# 《破壁机计划》卡牌数值定稿 v3.0

> 策划 2026-10-08 提供。本文为**原文落档**，转写与实现以本文为准。

## 通用规则
- 素材卡 **H 仅分 5 / 10 / 20 三档**：5=普通，10=稀有，20=传说。
- 法术卡**不标 H/D/V**，只标稀有度：普通 / 稀有 / 传说。
- 启动得分 = 目标 V + 刀片 V。
- 献祭吞噬条件：每回合最后一次启动，目标结算后 D>0 则并入刀片。
- 不衰退：层数不会随回合衰退；不会因为启动衰退；冷热之间会按照规则互相抵消；会被"消耗所有 X 层数"消耗。

**冰**｜素材｜固体｜标签 固体·可熔·遇热·献祭｜形态转换 可熔+热 → 水｜D耗尽 水 + 空白卡｜启动 若刀片冷层数≥3，则本次启动额外产生一张冰霜法术进手牌｜献祭 刀片附带一层不衰退的冷｜H5 D3 V2

**水蒸气**｜素材｜气体｜标签 气体·遇冷·献祭｜形态转换 遇冷+冷 → 水｜D耗尽 空白卡｜启动 若刀片有热附魔，则不消耗热层数，且本次启动得分翻倍；若刀片有冷附魔，则不消耗冷层数，且本次启动得分翻倍｜献祭 刀片附带一层不衰退的冷｜H5 D2 V2

## 十二、法术（不标 H/D/V，只标稀有度）
**火焰**｜附魔 热｜效果 附魔2层热到刀片，可叠加。每回合结束衰减｜普通

**余温**｜附魔 热｜效果 所有"火焰"法术，附加"热"的层数+1｜稀有

**冰霜**｜附魔 冷｜效果 附魔2层冷到刀片，可叠加。使刀片H+1｜普通

**酸蚀**｜附魔 酸｜效果 附魔2层酸到刀片，可叠加。每回合结束衰减｜普通

**酸爆**｜（无附魔类型）｜效果 使当前所有酸层数翻倍，减少刀片等同于当前酸层数的H，同时获得等同于当前酸层数的分数。如果通过此卡达成爆刀，爆刀产生的分数翻倍变为3倍｜传说

**催化术**｜附魔 催化｜效果 附魔1层催化到刀片，可叠加。每层催化降低热/冷/酸附魔触发阈值1点，最多降低2点｜稀有

**结晶**｜分类 直接得分｜效果 根据当前刀片冷层数直接加分，每层冷得2分｜普通

**硬化**｜（无附魔类型）｜效果 刀片H+10｜普通

## 与 v2.1 的关键差异（待实现清单，见转写报告）
1. **H 改三档**（5/10/20），法术不再有 H/D/V（改为稀有度字段）。
2. **大量新卡**：白磷、木头、碳、皮革、法术卷轴、铜/熔融铜/铜溶液/铜蒸气、铁/熔融铁/铁溶液/铁蒸气、黄金/熔融金、
   盐/盐溶液、汞/汞蒸气/固态汞、硫磺/硫磺气/硫磺液/硫磺粉、沙/熔融玻璃/玻璃、余温/冰霜/酸蚀/酸爆/结晶/硬化。
3. **每张卡的"启动"效果大幅扩写**（得分翻倍、不消耗 H、刀片 H±n、层数翻倍/消耗换分、额外产卡、D-2/D-3 持续被动、
   复制法术、随机法术、爆刀分数 3 倍…）→ 需要扩充规则文本词汇表与引擎算子。
4. **"献祭"效果几乎每张卡都有**（附带不衰退层数 / 一次性获得 N 层 / 加分 / 加 H/V / 被动型）。
5. **不衰退语义明确**：不随回合衰退、不因启动衰退、冷热之间仍互相抵消、会被"消耗所有 X 层数"消耗。
6. 火焰由"附魔1层热"改为"**附魔2层热**"；新增"余温"作为火焰的强化卡。
