## 一、游戏概述

《破壁机计划》是一款单机炼金卡牌游戏。玩家每关拥有一个刀片，刀片H代表本关可启动次数。玩家通过出牌、启动素材、触发附魔连锁、形态变化、D耗尽，获取分数。达到目标分即胜利。每关4回合，每回合初始5次行动机会。每回合最后一次启动的目标素材，若启动结算后仍有D剩余，则自动并入刀片，补充刀片H与V。刀片H归零则爆刀，关卡结束，当前分数×2。

游戏核心是确定性的炼金反应结算。所有卡牌形态变化由附魔规则硬编码驱动，素材通过标签与附魔层数交互，产生形态变化、副产物、法术，并回到手牌形成连锁。

## 二、核心玩法

### 2.1 卡牌类型

- 素材卡：拥有H、D、V，形态，标签，连锁规则，D耗尽规则。可出到桌面，可被启动，可作为刀片核心，可被吞噬并入刀片。
- 法术卡：无H/D/V。分三类：附魔法术、直接得分法术、影响素材法术。打出无代价，不消耗行动机会。附魔法术附魔到刀片；直接得分法术立即加分；影响素材法术立即作用于桌面素材。
- 特殊卡：空白卡。无特性，无法交互，所有数值为0，可并入刀片。需单独统计数量。

### 2.2 三属性

- H：珍稀度/耐久。素材作为刀片核心或并入刀片时，H全额加到刀片H。刀片H是本关启动次数池。
- D：使用次数。每次被启动，若未发生形态变化，则D-1。D≤0触发D耗尽。
- V：得分。每次启动得分 = 目标素材V + 刀片V。V枚举映射：极低=1，低=2，中=3，高=5，极高=8。暂时还没有设计具体数值，等待第二周设计关卡一并处理

### 2.3 形态与标签

- 每张卡有独立形态。形态变化 = 旧卡移除，新卡进手牌。新卡D重置为满。
- 标签分三类：
  - 形态标签：固体、液体、气体、粉末
  - 性质标签：易燃、可熔、可溶、氧化、催化、挥发、磁性、有毒、惰性、献祭（献祭意为，被刀片吞噬时，会触发效果）
  - 反应标签：遇热、遇冷、遇酸、遇水
- 形态变化由附魔规则表硬编码触发。

### 2.4 附魔

- 四种附魔：热、冷、酸、催化。
- 附魔到刀片，层数无上限。每回合结束衰减1层。
- 冷热冲突：后附魔覆盖先附魔，清空对方全部层数。酸催共存。
- 启动时不消耗附魔层数。

### 2.5 刀片

- 刀片是跨回合容器。每关重置。
- 每关开始时，玩家从初始手牌中选择一张素材作为刀片核心。该卡的H成为刀片初始H，V成为刀片初始V。该卡从手牌移除。剩余3张素材和1张法术进入手牌。
- 刀片V：得分加成。并入素材时，素材V加到刀片V。
- 刀片D：取消。
- 每回合最后一次启动的目标素材，若启动结算后仍有D剩余，则自动并入刀片。并入后本关不再回归。
- 刀片H≤0立即爆刀，关卡结束，当前分数×2。

### 2.6 关卡

- 每关4回合。每回合初始5次行动机会。
- 初始手牌：4张素材 + 1张法术。手牌无上限，出牌不消耗行动机会。
- 达到目标分即胜利。回合耗尽、爆刀、玩家主动结束则关卡结束。
- 每关独立，献祭与消耗不影响下一关。

## 三、回合流程

1. 回合开始：行动机会重置为5。附魔层数不变。
2. 行动阶段：玩家可自由出牌（不消耗行动机会）。点击“启动破壁机”，选择桌面一张素材作为目标。
3. 启动结算：消耗1行动机会 + 1刀片H。执行启动结算流程。
4. 重复启动：直到行动机会用尽或玩家主动结束回合。
5. 最后一次启动：每回合实际使用的最后一次启动，其目标素材在启动结算后，若仍有D剩余，则自动并入刀片。
6. 回合结束：所有附魔层数-1，归零消失。桌面素材保留。进入下一回合。
7. 关卡结束：4回合结束，或达到目标分，或爆刀，或玩家主动结束。结算最终分数。

## 四、启动结算流程

每次启动按以下顺序结算：
1. 消耗资源：消耗1行动机会 + 1刀片H。
2. 结算素材：
  - 按 热 → 冷 → 酸 → 催化 顺序检查刀片附魔。
  - 每种附魔根据层数、目标标签，查询硬编码规则表，触发最高优先级的一条效果。
  - 若触发形态变化：旧卡从桌面移除，新卡进手牌，新卡D重置为满。本次启动不再进行D-1。
  - 若触发溶解移除：旧卡移除，本次启动结束素材结算。
  - 若未发生形态变化：目标素材D-1。若D≤0，触发D耗尽：
    - 产生一张法术卡进手牌。
    - 产生一张或多张副产物素材卡进手牌。
    - 副产物可继续拥有D，可再次被启动并连锁。
    - 若没有任何产物，则生成一张空白卡进手牌，空白卡计数+1。
    - 原卡从桌面移除。
3. 结算收益：计算本次启动得分 = 目标素材V + 刀片V。若目标素材已因形态变化或D耗尽移除，则使用启动时的原始卡V。得分即时加入总分。
4. 检查爆刀：若刀片H≤0，立即爆刀，关卡结束，当前分数×2。
5. 献祭吞噬：若本次启动是本回合最后一次启动，且目标卡在结算后仍有D剩余（即未被形态变化或D耗尽移除），则将该卡并入刀片：
  - 该卡从桌面移除。
  - 刀片H += 该卡H。
  - 刀片V += 该卡V。
  - 若目标卡已因形态变化或D耗尽移除，则本次献祭不生效。

说明：最后一次启动不一定是第5次行动。若卡牌效果增加了行动机会，实际最后一次启动可能延后。这为增加启动次数的卡牌留出了设计空间。

## 五、附魔规则概述

附魔规则为硬编码表，按优先级从高到低匹配，每次只触发最高优先级一条。四种附魔分别对应不同标签组合，产生形态变化、燃烧、爆炸、溶解、冷凝、凝固、析出、金属液化等效果。具体规则表由策划维护，程序员按表实现。当前Demo中，催化附魔的主要作用是降低形态变化阈值：热≥2变热≥1，冷≥3变冷≥2，酸≥2变酸≥1。

# 附魔规则表

## A、通用检查顺序

每次启动，按以下顺序检查刀片附魔：
1. 热附魔
2. 冷附魔
3. 酸附魔
4. 催化附魔（仅修正其他附魔的触发阈值，不直接改变素材）

每个附魔类型内，按优先级从高到低匹配，只触发最高优先级的一条规则。
- 若触发的规则导致形态变化或移除，则旧卡移除，新卡进手牌，本次启动的素材结算结束，不再检查后续附魔。
- 若触发的规则仅修改属性（如H-1）且未导致形态变化，则继续检查下一个附魔类型。
- 催化附魔不直接作用于素材，而是在检查热、冷、酸附魔时，根据当前催化层数降低其触发阈值。

## B、热附魔规则

| 优先级 | 条件 | 结果 |
|---|---|---|
| 1 | 热≥1 且 目标有易燃 | 燃烧：目标D立即归零，变为该卡指定的燃烧产物 |
| 2 | 热≥1 且 目标为粉末且易燃 | 爆炸：目标H归零，刀片热层数+1，目标变为空白卡 |
| 3 | 热≥2 且 目标为液体 | 目标变为该卡指定的气态形态 |
| 4 | 热≥2 且 目标有遇热 | 触发该卡指定的热反应（形态或属性变化） |
| 5 | 热≥3 且 目标为金属 | 目标变为该卡指定的熔融形态 |
| 6 | 热≥3 且 目标有可熔 | 目标变为该卡指定的液态形态 |
| 7 | 其他 | 无变化 |

## C、冷附魔规则

| 优先级 | 条件 | 结果 |
|---|---|---|
| 1 | 冷≥2 且 目标为气体 | 目标变为该卡指定的液态形态 |
| 2 | 冷≥3 且 目标为液体 | 目标变为该卡指定的固态形态 |
| 3 | 冷≥2 且 目标为溶液 | 析出该卡指定的固态副产物，副产物进手牌 |
| 4 | 冷≥1 且 目标有遇冷 | 触发该卡指定的冷反应（形态或属性变化） |
| 5 | 其他 | 无变化 |

## D、酸附魔规则

| 优先级 | 条件 | 结果 |
|---|---|---|
| 1 | 酸≥1 且 目标为金属 | 目标变为该卡指定的溶液，目标H-2 |
| 2 | 酸≥1 且 目标有可溶 | 目标变为该卡指定的溶液 |
| 3 | 酸≥2 且 目标为固体 | 目标H-1；若H归零，则变为该卡指定的粉末形态 |
| 4 | 酸≥1 且 目标为粉末 | 目标溶解移除，不产生副产物 |
| 5 | 酸≥1 且 目标有遇酸 | 触发该卡指定的酸反应（形态或属性变化） |

## E、催化附魔规则

催化附魔不直接改变素材形态，而是全局修正热、冷、酸附魔的触发阈值。

| 催化层数 | 修正效果 |
|---|---|
| 催≥1 | 热附魔阈值-1（热≥2→热≥1，热≥3→热≥2） |
| 催≥1 | 冷附魔阈值-1（冷≥2→冷≥1，冷≥3→冷≥2） |
| 催≥1 | 酸附魔阈值-1（酸≥2→酸≥1） |
| 催≥3 | 阈值再-1（可叠加，但当前Demo暂不开放） |

说明：催化层数本身不消耗，每回合结束与其他附魔一同衰减1层。催化不触发“额外普通反应”等旧机制。

## F、阈值修正示例

假设刀片当前有：热2、冷0、酸0、催1。
- 检查热附魔：原本“热≥2 + 液体”可触发。因催≥1，阈值降为热≥1，所以热≥1即可触发。
- 检查冷附魔：原本“冷≥2 + 气体”可触发。因催≥1，阈值降为冷≥1。
- 检查酸附魔：原本“酸≥1 + 金属”可触发。因催≥1，阈值不变（酸≥1已是最低）。

## E、形态变化与D处理

- 若附魔规则导致形态变化：旧卡从桌面移除，新卡进手牌，新卡D重置为满。本次启动不再对旧卡进行D-1。
- 若附魔规则导致溶解移除：旧卡从桌面移除，不产生副产物。本次启动结束。
- 若附魔规则仅修改属性（如H-2、H-1）且未导致形态变化：继续检查下一个附魔类型。所有附魔检查完毕后，若目标仍存在，则目标D-1；若D≤0，触发D耗尽。
- D耗尽产生的法术与副产物直接进手牌。无产物则生成空白卡进手牌，空白卡计数+1。

## F、附魔衰减与冲突

| 规则 | 说明 |
|---|---|
| 衰减 | 每回合结束，所有附魔层数-1，归零消失 |
| 冷热冲突 | 后附魔覆盖先附魔，清空对方全部层数 |
| 酸催共存 | 酸与催化,与其他附魔都不冲突，可同时存在 |
| 启动消耗 | 启动时无论是否发生效果，消耗1层附魔层数 |
| 层数上限 | 无上限 |

## G、规则表维护说明

- 本表为硬编码规则，由策划维护，程序员按表实现。
- 新增卡牌时，只需在卡牌定义中标注标签、连锁产物、D耗尽产物，即可自动接入本规则表。
- 若新增附魔类型或标签类别，需同步扩展本表。

## 六、刀片与献祭规则细节

- 刀片核心选择：每关开始时，玩家从初始4张素材中选择1张作为刀片核心。该卡H成为刀片初始H，V成为刀片初始V。该卡从手牌移除，不参与本关后续出牌。
- 刀片H：本关启动次数池。每次启动消耗1点。H≤0立即爆刀，关卡结束，当前分数×2。
- 刀片V：得分加成。每次启动得分包含刀片V。并入素材时，素材V加到刀片V。
- 献祭吞噬：每回合最后一次启动的目标素材，若启动结算后仍有D剩余，则自动并入刀片。若D已耗尽或发生形态变化，则无法吞噬。
- 并入后不回归：被吞噬的卡本关不再回到手牌或桌面。
- 空白卡：所有数值为0，可被吞噬，但不提供H/V。需单独统计数量。

## 七、规则细节确认

以下为之前商讨中确认的规则细节，需在策划书中明确：
1. 素材副产物回手牌：D耗尽产生的法术卡与副产物素材卡，直接进入手牌，可再次出牌、启动、连锁。
2. 先结算素材，再结算收益：启动时先执行附魔连锁、形态变化、D耗尽等素材结算，再计算本次得分。得分使用启动时的原始卡V（若目标已移除）或当前卡V（若仍存在）。
3. 最后一次启动才是献祭：每回合实际使用的最后一次启动，其目标素材才可能被吞噬。这为增加行动机会的卡牌留出空间，使回合行动次数可超过5次。
4. 只有D有剩余才能吞噬：最后一次启动结算后，若目标卡仍有D剩余，则并入刀片。若D耗尽或发生形态变化，则无法吞噬。
5. 附魔衰减：每回合结束，所有附魔层数-1，归零消失。
6. 冷热冲突：后附魔覆盖先附魔，清空对方全部层数。酸催共存。
7. 启动不消耗附魔层数：附魔层数仅在回合结束衰减，启动时只读取层数，不扣除。
8. 形态变化新卡进手牌：旧卡移除，新卡进手牌，D重置为满。
9. 同一形态组允许多张同时存在。
10. 手牌无上限，出牌不消耗行动机会。
11. 法术打出无代价，不消耗行动机会。
12. 每关独立：献祭、消耗、分数均不跨关继承。

## 八、关卡与胜负

- 每关4回合，每回合初始5次行动机会。
- 初始手牌：4张素材 + 1张法术。玩家选择1张素材作为刀片核心后，剩余3素材+1法术进入手牌。
- 胜利条件：达到目标分。
- 关卡结束条件：4回合耗尽、爆刀、玩家主动结束、达到目标分。
- 爆刀结算：刀片H≤0时立即爆刀，当前所有分数×2，关卡结束。
- 主动结束：玩家可主动结束关卡，按当前分数结算，不触发爆刀双倍。
- 每关独立：关卡之间不继承手牌、刀片、分数、附魔。

## 九、功能需求概述

- 卡牌数据加载：从配置加载素材、法术、特殊卡定义，支持形态组、标签、连锁、D耗尽配置。
- 游戏状态管理：关卡、回合、分数、目标分、行动机会、刀片状态、手牌、桌面、弃牌堆、空白卡计数。
- 出牌与启动：手牌可拖拽到桌面；点击启动按钮选择桌面素材；消耗行动机会与刀片H。
- 结算引擎：按顺序执行消耗资源、素材结算、收益结算、爆刀检查、献祭吞噬。
- 附魔系统：四种附魔层数管理，冷热冲突，回合结束衰减，启动时读取并触发规则表。
- 形态变化：旧卡移除，新卡进手牌，D重置。
- D耗尽：产生法术与副产物进手牌，无产物则生成空白卡并计数。
- 刀片管理：显示H、V、附魔层数、词条；爆刀时分数×2并结束关卡。
- 回合与关卡：回合开始重置行动机会；回合结束衰减附魔；关卡结束条件判断。
- UI与表现：手牌区、桌面区、刀片区、行动机会、分数、回合数、空白卡计数、启动按钮、动画与日志。
- 存档与读档：保存当前关卡状态，支持重新开始本关。

## 十、当前卡牌体系概览

当前已设计素材卡、法术卡、特殊卡共若干。素材卡覆盖水、木头、铁、铜、硫磺、硝石、制冷剂、酸液、催化剂等系列，每个系列包含多张独立形态卡，通过附魔连锁相互转化。法术卡分附魔、直接得分、影响素材三类。特殊卡为空白卡。具体卡牌列表与数值详见卡表文件，本策划书不展开。
