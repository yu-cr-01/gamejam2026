# 关卡、商店与隐藏房规则 v1

本文件对应 Unity 桌面流程的 `campaign_v1.json`、`game_config.json`、`shop_v30.json`。NPC、教程、商店和隐藏房文案集中在 `campaign_v1.json`；目标分写在 `game_config.json`；商店卡池、稀有度权重与价格写在 `shop_v30.json`。

## 战役关卡

| 关卡 | 目标分 | 特殊条件 |
| --- | ---: | --- |
| 导师 | 60 | 无 |
| 火女 | 120 | 开局额外获得 3 张一次性火焰法术 |
| 眼球骑士 | 180 | 刀片开局获得 3 层不衰退的冷附魔 |
| 导师本源形态 | 300 | 每次启动的目标 V + 刀片 V 总分减半；每次真实形态变化额外 +10 分 |

每关四回合，每回合五次启动。关卡目标分从关卡配置读取，不再统一覆盖为 60。普通关卡在进入游戏后先显示目标和特殊条件，再播放 NPC 初遇；首个启动后播放嘲讽；第二回合开始播放催促；第三回合开始播放称赞；第四回合结束播放告别。所有文案集中配置。

## 新手教程

教程在首次开始游戏时替代第一关。导师介绍破壁机、量杯和桌面，然后让玩家从三副初始牌组中选择，再选刀片。选择刀片后介绍水卡 H/D/V 与本关 60 分目标。第一回合第四次启动完成后，提示第五次启动会献祭目标素材，只有 D 大于 0 才能并入刀片。第一回合商店播放导师对商店的介绍。

教程胜利或失败都会进入导师结语并自动开始第二关。教程完成状态保存在 Unity `PlayerPrefs`，之后重新开始不再重复教程。教程、图文说明和结语文案集中在 `campaign_v1.json`。

## 商店

第一、二、三回合结束后依次出现盐、硫、汞商店。每店展示五个货位：先抽一张法术，再按当前权重抽四张卡；普通、稀有、传说基础权重为 10、3、1。四张随机卡每抽到一次，该卡在本次商店的权重减半。法术抽取不改变随机卡权重。商店内重复卡允许出现；每个货位各自只能买一次，所以同名重复卡是独立货位。价格为普通 1 分、稀有 2 分、传说 3 分。

分数不够时货位禁用；购买扣分并把素材或法术加入手牌。每家商店可消耗一张空白卡，重抽库存两次；两次重抽沿用本次访问已衰减的权重。离开商店后开始下一回合。具体卡池保留在 `shop_v30.json`，其中金蒸气仍作为待补属性的传说卡存在。

## 隐藏房

每次关卡结算时分别掷汞之间与献祭房概率。汞之间概率为 `10% + 10% × 自上次触发后新增的空白卡张数`，上限 100%；触发后清零该进度。献祭房概率等于自上次触发后成功并入刀片的素材 H 总和，上限 100%；触发后清零该进度。概率进度与商店可消费的空白卡库存分开保存，消费空白卡不会降低汞之间概率；献祭房奖励的 5 张空白卡也会增加汞之间进度。

汞之间把桌面换成银白底色，显示主角感悟，固定提供汞、固态汞、汞蒸气三选一，选中的素材进入手牌，然后从二阶职业池抽三选一。献祭房把桌面换成黑灰底色，显示等价交换主题感悟，进入房间时奖励五张空白卡，再从一阶职业池抽三选一。房间职业允许重复记录，并独立于普通职业树，不参与升阶。

按当前设计决定，两个职业候选池先留空；空池时隐藏房会显示暂不提供职业奖励，并允许继续流程。后续补入职业名称、阶级和效果后，可通过 `hiddenRooms.tierOneProfessions` 与 `hiddenRooms.tierTwoProfessions` 启用三选一；职业效果仍需接入规则结算。
