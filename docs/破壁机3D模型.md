# 破壁机参考图建模

参考：`UnityProject/Assets/Resources/Art/Juicer/gameblender_normal_img.png`。

模型：`UnityProject/Assets/Resources/Art/Juicer/Models/blender_reference.obj`，配套同目录 MTL、深蓝灰纸纹 `enamel_brush.png` 和暖纸色 `glass_paper.png`。使用 Y 轴向上，可在 3ds Max 的“导入”中打开 OBJ；没有生成原生 MAX 文件。

37 个命名部件，5,156 个三角面。底座、玻璃内外壁、壶口、宽厚的小孔把手、盖、旋钮、刻度、液体与内部刀片都有独立几何。轮廓略不规则，背面散热孔是依据单张正面参考补全的细节；正面不再添加参考图中没有的电源开关。

Unity 使用 `IllustratedProp.shader` 的黑色轮廓和分档哑光色块，结合纸纹、墨洗斑块和暖纸色壶壁贴近原图的手绘风格。源生成脚本依赖 Python、Pillow、NumPy 和 SciPy。蜡烛及其烛光不再创建，左侧计分量筒保留原有位置；固定桌面柔光维持照明。

运行 `python Tools/Art/build_reference_blender.py` 可重新生成资源。`BlenderModelRig` 加载导入模型，适配原机位和桌面大小，配置玻璃/搪瓷/液体材质，并响应 `JuicerRig.IsStamping` 播放震动和刀片旋转。模型存在时不再搭建旧程序化机架；原 PNG 资源保留为缺失模型时的回退。

Unity 导入 OBJ 时会翻转 X 轴，装配组件补偿该镜像以保留立绘右侧把手。原始 OBJ 在外部软件中的轴向可按软件的导入设置调整。
