## 3. 三类"不是抄错、但要人拍板"的事

### 3.1 原文引用了一张卡表里没有的卡：「灰烬」

- 原文：「法术卷轴｜…｜形态转换 易燃+热 → **灰烬**；遇酸+酸 → 灰烬」
- 卡表：`spell_scroll.transitions` 两条产物都写的是"灰烬"，但**卡表里没有「灰烬」这张卡**
  （v3.0 定稿的 31 张素材里没有它；v2.1 卡表里当时是有的，id=`ash`）。
- 后果：引擎命中这条反应时按名字查不到卡 → 产出进"可疑产出"清单（报告里 1 条），**不会静默**，
  但那张产物在游戏里是产不出来的。
- **本次没有动它**：按"转写以原文为准"，不能自作主张给 v3.0 加一张原文没列的卡。
  请策划二选一：① 把「灰烬」补进定稿卡表（给 H/D/V/标签）；② 把法术卷轴的形态转换产物改成卡表里已有的卡。

### 3.2 「法术卷轴」的献祭要玩家选牌

- 原文：「指定手牌中的1张法术卡，复制2张」。
- 这句在解析器眼里是**认不出来**的（没有"指定手牌"这种交互模型）—— 已进未识别清单，
  不会静默失效。见缺口报告的 ❌/交互类。

### 3.3 刀片 V / 桌面条件 / 受击触发这三类写法

- 「木头」献祭「若桌面上的卡牌为水，启动时，刀片V+1」：既依赖"桌面某张卡是水"这种**跨卡条件**，
  又依赖"刀片 V+1"这个**模型里没有的量**（引擎的刀片只有 H + 四种层数，没有 V）。
  卡表按原文照抄，未识别清单里如实列着。
- 「熔融金」献祭「刀片减少5H，额外增加10V」：同一句里 H-5 认得出、`增加10V` 认不出 →
  属于"半懂字段"（报告里单列一节），整句不生效。
- 「固态汞」「熔融玻璃」「玻璃」的献祭是**反应式触发**（"每次…时，…"）：引擎当前只有
  "启动"这一个结算时机，没有"层数变化/受击"的钩子，所以整句认不出来。
