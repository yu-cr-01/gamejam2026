# Windows 试玩版 · 2026-10-15

## 运行方法

下载发布页的 Windows ZIP，解压整个文件夹后，运行 `破壁机计划.exe`。
请保留 EXE 同目录的 `破壁机计划_Data`、`UnityPlayer.dll` 及其他文件，不要只单独复制 EXE。

## 本次更新

- 破壁机接入参照原立绘制作的 3D 模型，调整材质与把手，移除蜡烛。
- 统一主菜单、关卡、商店、回合结算等界面风格和字体，槽位文字放入框内。
- 精简界面主题文案和新手说明，放大计分板。
- 桌面摄像机对准桌子中轴，推近取景，使卡牌显示更大。
- 包含当前项目中的关卡、隐藏房间及回合流程更新。
