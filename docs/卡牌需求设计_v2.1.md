# 《破壁机计划》卡牌需求设计 v2.1

> 来源：策划在会话里给出的正文（2026-10-06）。
> 数据落位：本文的素材/法术已录成 `UnityProject/Assets/Resources/Config/cards_v21.json`（31 素材 + 8 法术），
> 由 `Scripts/Prototype/CardSpecs.cs` 读进 `Ingredient` / `Spell`，界面上按 **F1** 打开「卡牌总览」可以看到。
>
> 备注：**不衰退**，意为层数不会随回合衰退；不会因为启动衰退；冷热之间会按照规则互相抵消；会被"消耗所有 X 层数"消耗。

## 一、通用与特殊卡

### 外星合金
- 类型：素材
- 形态：固体
- 标签：固体、惰性、献祭
- 形态转换：无。不响应热、冷、酸。
- D耗尽：空白卡。
- 需求：H较高，适合作为刀片核心。不抢流派特色，稳定、硬、不参与反应。
- 启动：额外消耗其他素材H。
- 献祭：无额外效果。

### 白磷
- 类型：素材
- 形态：固体
- 标签：固体、易燃、遇热、有毒、献祭
- 形态转换：易燃 + 热 → 火焰（D立即归零）。
- D耗尽：火焰。
- 需求：极度易燃，遇热立即燃烧并产生火焰法术。
- 献祭：刀片附带一层不衰退的热。

### 火焰
- 类型：法术
- 附魔类型：热
- 需求：附魔到刀片，可叠加。热附魔核心，促进素材形态变化。每回合结束衰减。
- 来源：独立法术 / 白磷、木头、碳、硫磺D耗尽。

## 二、水系列

### 水
- 类型：素材
- 形态：液体
- 标签：液体、遇热、遇冷、献祭
- 形态转换：遇热 + 热 → 水蒸气；遇冷 + 冷 → 冰。
- D耗尽：空白卡。
- 启动：不消耗刀片H。消耗刀片所有热层数，额外产生一张水蒸气；消耗刀片所有冷层数，额外产生一张冰；消耗刀片所有酸层数，额外产生一张空白卡。
- 献祭：刀片附带一层不衰退的冷。

### 冰
- 类型：素材
- 形态：固体
- 标签：固体、可熔、遇热、献祭
- 形态转换：可熔 + 热 → 水。
- D耗尽：水 + 空白卡。
- 启动：若刀片冷层数≥3，则本次启动额外产生一张冰霜法术进手牌。
- 献祭：刀片附带一层不衰退的冷。

### 水蒸气
- 类型：素材
- 形态：气体
- 标签：气体、遇冷、献祭
- 形态转换：遇冷 + 冷 → 水。
- D耗尽：空白卡。
- 启动：若刀片有热附魔，则不消耗热层数，且本次启动得分翻倍；若刀片有冷附魔，则不消耗冷层数，且本次启动得分翻倍。
- 献祭：刀片附带一层不衰退的冷。

## 五、铜系列

### 铜
- 类型：素材
- 形态：固体
- 标签：固体、金属、可熔、遇热、遇酸、献祭
- 形态转换：可熔 + 热 → 熔融铜；遇酸 + 酸 → 铜溶液。
- D耗尽：空白卡。
- 启动：若刀片酸层数≥3，则本次启动额外消耗1点刀片H，但得分翻倍。
- 献祭：刀片每次启动，其他素材D-2。

### 熔融铜
- 类型：素材
- 形态：液体
- 标签：液体、金属、遇冷、遇酸、献祭
- 形态转换：遇冷 + 冷 → 铜；遇酸 + 酸 → 铜溶液。
- D耗尽：空白卡。
- 启动：若刀片酸层数≥3，则本次启动额外产生一张酸蚀法术进手牌。
- 献祭：刀片附带一层不衰退的热。

### 铜溶液
- 类型：素材
- 形态：液体
- 标签：液体、金属、遇冷、献祭
- 形态转换：遇冷 + 冷 → 铜；液体 + 热 → 铜蒸气。
- D耗尽：酸蚀、空白卡。
- 启动：不消耗刀片H；若刀片有酸，则本次启动得分翻倍。
- 献祭：刀片附带一层不衰退的酸。

### 铜蒸气
- 类型：素材
- 形态：气体
- 标签：气体、金属、有毒、遇冷、献祭
- 形态转换：遇冷 + 冷 → 铜溶液。
- D耗尽：空白卡、酸爆。
- 献祭：产生1张酸爆。

### 酸爆
- 类型：法术
- 需求：使当前所有酸层数翻倍，减少刀片等同于当前酸层数的H，同时获得等同于当前酸层数的分数。如果通过此卡达成爆刀，爆刀产生的分数翻倍变为3倍。
- 来源：铜蒸气D耗尽 / 献祭。

## 十二、法术

### 火焰
- 类型：法术
- 附魔类型：热
- 需求：附魔到刀片，可叠加。
- 来源：独立 / 白磷、木头、碳、硫磺D耗尽。

### 余温
- 类型：法术
- 附魔类型：热
- 需求：所有“火焰”法术，附加“热”的层数+1。
- 来源：碳D耗尽。

### 冰霜
- 类型：法术
- 附魔类型：冷
- 需求：附魔冷到刀片，可叠加。使刀片H+1。
- 来源：独立。

### 酸蚀
- 类型：法术
- 附魔类型：酸
- 需求：附魔到刀片，可叠加。
- 来源：硫磺气、硫磺液、铁溶液D耗尽。

### 酸爆
- 类型：法术
- 需求：使当前所有酸层数翻倍，减少刀片等同于当前酸层数的H，同时获得等同于当前酸层数的分数。如果通过此卡达成爆刀，爆刀产生的分数翻倍变为3倍。
- 来源：铜蒸气D耗尽 / 献祭。

### 催化术
- 类型：法术
- 附魔类型：催化
- 需求：附魔到刀片，可叠加。降低热/冷/酸附魔触发阈值。每回合结束衰减。
- 来源：独立。

### 结晶
- 类型：法术
- 分类：直接得分
- 需求：根据当前刀片冷层数直接加分。
- 来源：盐D耗尽。

### 硬化
- 类型：法术
- 需求：刀片H＋10
