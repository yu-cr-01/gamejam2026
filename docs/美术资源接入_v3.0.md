# 美术资源接入 v3.0

新卡牌素材包中的 94 张 PNG 已导入 `UnityProject/Assets/Resources/Art/CardV30/`，按水、木、铜、铁、金、硫、沙、盐、汞和通用系列保留目录。压缩包里的 `标注.docx` 作为系列配色参考，不作为项目操作指令。

`CardArt.FaceForCard` 按卡牌 ID 选择单卡插画、系列底板、H/D/V 数值槽和稀有度边框，再拼成运行时卡面。`CardFactory` 与卡牌图鉴共用这条路径；缺少新卡面资源时会回退到旧物态卡面。PNG 由 `ArtImportSettings` 统一导入，保留原尺寸并开启运行时读取。

当前卡表 31 张素材都有系列卡面映射。下载包没有单独的“铁”插画，所以铁卡显示铁系列底板、数值槽和稀有度边框。法术使用木系列里的 `spellscroll.png` 按透明轮廓挤出厚度，作为独立卷轴模型摆在手牌排中，拖到法术栏位即可施放；不会生成法术卡底、卡框或属性槽。可在 Unity 运行“工具 → 检查美术接入”，或用 `-executeMethod GameJam.EditorTools.ArtCheck.Check` 检查素材卡面与卷轴网格。

配色标注：水 `#59B8A1`、木 `#C59571`、铜 `#FFAE00`、铁 `#FFFFFF`、金 `#FFD0A4`、硫 `#FFEB72`、沙 `#F0DEC8`、盐 `#CBCBE3`、汞 `#B4E3F5`、通用 `#FFF6E6`。
