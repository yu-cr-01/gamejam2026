# 商店与卡牌管线 v3.0

卡牌规则以 `UnityProject/Assets/Resources/Config/cards_v21.json` 为运行时卡表；商店池、稀有度权重和购买价格以 `shop_v30.json` 为准。卡表文件名暂时沿用旧路径，避免破坏 Unity Resources 与现有工具引用。

第一、二、三回合结束后分别进入盐、硫、汞商店。每店展示 5 个货位：先从该商人的池中按稀有度抽 1 张法术，再独立抽 4 张素材或法术。重复卡允许出现；固定法术抽取不影响随机卡权重，每个随机货位抽完后，同名卡的当前权重减半。商店重抽沿用本店之前的权重记录。

普通、稀有、传说卡的基础抽取权重分别为 10、3、1，购买价格分别为 1、2、3 分。已购货位不能再次购买，购买后卡牌进手牌。分数不足的货位禁用。离开商店会进入下一回合。

每店最多支付 1 张空白卡，支付后获得 2 次重抽机会。首次支付前会显示该商人的专属确认文案；每次重抽刷新全部 5 个货位，但保留已衰减的卡牌权重。

素材卡新增层数默认永久，不随回合结束或启动衰减；只有卡牌规则明确写出消耗层数时才移除。冷热冲突仍由附魔覆盖规则处理。旧存档中的衰退计数仍可读取，但不会再生成新衰退层。

当前汞商人池保留 `gold_vapor`（金蒸气，传说）这一策划项。卡牌定义补齐前，它仍参与权重抽取，并显示为不可购买的“属性待定”货位，不会改变定稿总权重。新增或修改商店池后运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File Tools/RuleProbe/shop_check.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File Tools/RuleProbe/run.ps1
```

已确认的卡表修正包括：火焰、冰霜、酸蚀各附魔 1 层；水蒸气献祭附带热；法术卷轴形态转换产物为碳。旧属性 ID 已统一为 `H / D / V`。
